Not seeing your other device?
  • Both devices must run LANyard and be on the same network (same Wi-Fi or cable). Guest networks and some routers isolate devices from each other.
  • Windows Firewall: when Windows asks whether to allow LANyard, choose Private networks and Allow access. If you skipped it: Windows Security → Firewall & network protection → Allow an app through firewall → LANyard → tick Private.
  • macOS and Linux: allow incoming connections for LANyard if your firewall asks (ports 47800 TCP, 47801 UDP, and UDP 5353 for discovery).
  • On a VPN or another subnet, devices cannot find each other automatically: use Add by address above with the other device's IP address and the port shown at the top of its window.
